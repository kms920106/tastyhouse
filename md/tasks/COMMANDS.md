# 작업지시서별 실행 명령어

각 작업지시서를 독립된 AI 세션(Claude Code 등)에 그대로 붙여넣을 수 있는 명령어다. 병렬로 여러 세션에 동시 투입해도 안전한 작업(서로 다른 파일/모듈을 다룸)과, 순서를 지켜야 하는 작업을 구분해뒀다.

## 병렬 투입 가능 여부

- **동시에 여러 세션에 투입해도 안전**: 01, 02, 04, 06, 07, 08, 09 (서로 다른 파일/모듈을 건드림)
- **03과 05는 04·06과 일부 겹칠 수 있음**: 03(SearchApiController, PathVariable)과 05(FileService 호출부)는 web-api/admin-api 전반을 넓게 건드리므로, 가능하면 03·05는 다른 작업이 끝난 뒤 순차 실행 권장. 03·05를 동시에 다른 세션에 돌리는 것은 피할 것(같은 컨트롤러 파일을 동시에 수정할 위험).
- **02 → 05 권장 순서**(강제 아님): 02가 먼저 끝나면 정식 포트/타입 참조 패턴이 정리되어 05 작업이 매끄럽다.
