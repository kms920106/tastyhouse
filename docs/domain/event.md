# 이벤트(event) 도메인

## 이 도메인은 무엇인가

서비스가 회원에게 알리는 이벤트와 프로모션을 관리한다. 관리자가 이벤트를 만들어 기간과 내용을 설정하고, 회원은 앱·웹에서 진행 중인 이벤트 목록과 상세 내용을 확인한다. 이벤트가 끝나면 관리자가 당첨자를 등록하고 당첨 발표 공지를 올려 결과를 알린다.

이벤트 참여를 접수하거나 당첨자를 자동으로 뽑는 기능은 이 도메인에 없다. 응모(참여 신청)와 추첨은 서비스 밖에서 이루어지고, 이 도메인은 **이벤트를 알리는 것**과 **정해진 당첨 결과를 게시하는 것**을 담당한다.

## 핵심 개념

**이벤트**
하나의 이벤트를 나타내는 기본 단위다. 다음 정보를 갖는다.

- 이벤트명, 부제목, 짧은 설명
- 목록에 보이는 썸네일 이미지와 상세 화면에 보이는 배너 이미지
- 상세 화면에 표시되는 본문 내용
- 진행 상태
- 시작 일시와 종료 일시

**당첨자**
한 이벤트에 대해 등록되는 당첨자 정보다. 당첨 순위, 당첨자 이름, 휴대폰 번호, 당첨 발표 일시를 갖는다. 한 이벤트에 여러 명을 등록할 수 있고, 목록은 순위 순서로 표시된다.

**당첨 발표 공지**
당첨 결과를 알리는 게시물이다. 제목, 내용, 발표 일시를 갖는다. **한 이벤트에는 발표 공지를 하나만 등록할 수 있다.** 발표 공지는 개별 당첨자 명단과는 별개로, 회원에게 "이 이벤트의 당첨자가 발표되었다"는 사실과 발표 내용을 전달하는 역할을 한다.

## 주요 업무 흐름

### 이벤트 등록부터 회원 노출까지

관리자가 관리자 화면에서 이벤트를 등록한다. 이벤트명·부제목·설명·본문을 작성하고, 목록용 썸네일 이미지와 상세용 배너 이미지를 업로드해 지정하고, 진행 기간과 진행 상태를 설정한다.

이벤트가 등록되면 회원은 웹·앱의 이벤트 목록에서 이를 볼 수 있다. 목록은 상태별로 조회되므로 회원은 "진행중"인 이벤트만 볼 수도 있고 "종료"된 이벤트를 따로 볼 수도 있다. 목록에는 이벤트명, 썸네일 이미지, 시작·종료 일시가 표시된다. 회원이 특정 이벤트를 누르면 배너 이미지가 포함된 상세 화면이 열린다.

이미지는 파일 도메인에 먼저 업로드해 두고 그 결과를 이벤트에 연결하는 방식이다. 화면에 필요한 이미지 주소는 조회 시점에 서버가 만들어 함께 전달하므로, 화면은 이미지 주소를 그대로 표시하면 된다.

### 이벤트 수정과 삭제

관리자는 등록된 이벤트의 모든 항목(이벤트명·설명·부제목·이미지·본문·상태·기간)을 수정할 수 있다. 삭제도 가능한데, 이때 데이터가 실제로 지워지는 것이 아니라 **삭제된 것으로 표시**되어 조회 결과에서 빠진다. 따라서 관리자 목록에도 회원 화면에도 더 이상 나타나지 않지만 기록 자체는 남는다.

### 당첨자 등록과 발표

이벤트가 종료되고 추첨이 끝나면 관리자가 당첨자를 등록한다. 당첨자 한 명마다 순위, 이름, 휴대폰 번호, 발표 일시를 입력한다. 등록된 당첨자 목록은 관리자 화면에서 순위 순서로 확인할 수 있고, 잘못 등록한 당첨자는 삭제할 수 있다. 당첨자 삭제 역시 실제로 지우는 것이 아니라 삭제된 것으로 표시하는 방식이다.

당첨자 명단과 별도로, 관리자는 그 이벤트의 당첨 발표 공지를 하나 등록한다. 이미 발표 공지가 등록된 이벤트에 또 등록하려 하면 "이미 당첨자 발표 공지가 등록된 이벤트입니다"라는 안내가 나온다. 이미 등록한 공지의 제목·내용·발표 일시는 나중에 수정할 수 있다.

회원은 웹·앱의 당첨자 발표 목록 화면에서 **모든 이벤트의 발표 공지를 한데 모아** 볼 수 있다. 이벤트별로 찾아 들어가지 않아도 최근 발표들을 순서대로 확인할 수 있는 구조다.

## 상태와 전이 규칙

| 상태 | 의미 |
|---|---|
| 예정 | 아직 시작되지 않은 이벤트 |
| 진행중 | 현재 진행되고 있는 이벤트 |
| 종료 | 기간이 끝난 이벤트 |

상태는 시작·종료 일시에 따라 자동으로 바뀌는 것이 아니라 **관리자가 직접 지정한다.** 이벤트를 등록할 때 상태를 정하고, 이후 수정 화면에서 상태를 바꿀 수 있다. 따라서 시작 일시가 지났더라도 관리자가 상태를 "진행중"으로 바꾸지 않으면 계속 "예정"으로 남는다. 반대로 정해진 순서가 강제되지 않으므로 관리자는 필요하면 어떤 상태에서든 다른 상태로 바꿀 수 있다.

당첨자와 발표 공지에는 별도의 상태가 없다. 등록되어 있거나 없거나 둘 중 하나다.

## 비즈니스 규칙

**이벤트당 발표 공지는 하나만 등록할 수 있다**
이미 발표 공지가 있는 이벤트에 다시 등록하려 하면 "이미 당첨자 발표 공지가 등록된 이벤트입니다"라는 안내가 나오고 등록이 되지 않는다. 내용을 바꾸려면 새로 등록하는 대신 기존 공지를 수정한다.

**존재하지 않는 이벤트에는 당첨자나 발표를 등록할 수 없다**
대상 이벤트가 없거나 이미 삭제된 경우 "이벤트를 찾을 수 없습니다"라는 안내가 나온다.

**없는 발표 공지는 수정할 수 없다**
발표 공지를 등록하지 않은 이벤트에서 수정을 시도하면 "당첨자 발표 공지를 찾을 수 없습니다"라는 안내가 나온다.

**없는 당첨자는 삭제할 수 없다**
이미 삭제되었거나 존재하지 않는 당첨자를 삭제하려 하면 "당첨자를 찾을 수 없습니다"라는 안내가 나온다.

**정해진 상태 값만 사용할 수 있다**
이벤트 상태는 예정·진행중·종료 세 가지뿐이며, 그 밖의 값을 넘기면 "알 수 없는 이벤트 상태입니다"라는 안내가 나온다.

**삭제된 이벤트는 목록에 나타나지 않는다**
관리자 목록과 회원 화면 모두 삭제 표시된 이벤트를 제외하고 조회한다.

**이미지는 필수가 아니다**
썸네일과 배너 이미지를 지정하지 않고도 이벤트를 등록할 수 있다. 이 경우 화면에는 이미지가 표시되지 않는다.

## 다른 도메인과의 관계

**파일**
이벤트의 썸네일 이미지와 배너 이미지는 파일 도메인에 업로드된 이미지를 가리킨다. 이벤트 자체는 이미지 파일을 갖지 않고 "어떤 이미지를 쓸지"만 연결해 둔다. 화면에 필요한 이미지 주소는 조회 시점에 만들어져 전달된다.

**회원**
회원은 이벤트를 조회하는 대상이다. 다만 당첨자 정보는 회원 계정과 연결되어 있지 않고, 관리자가 입력한 이름과 휴대폰 번호로만 관리된다. 따라서 어떤 회원이 당첨되었는지를 시스템이 자동으로 알지는 못한다.

**배너**
이벤트와 별개로 홈 화면 등에 노출되는 배너는 배너 도메인이 담당한다. 이벤트를 배너로 홍보하려면 배너 쪽에 별도로 등록해 연결 주소를 지정한다.

## 사용자별 접점

**일반 회원(웹)**
- 상태별 이벤트 목록 조회 (이벤트명, 썸네일 이미지, 시작·종료 일시)
- 이벤트 상세 조회 (배너 이미지)
- 전체 이벤트의 당첨자 발표 목록 조회 (제목, 내용, 발표 일시)

**관리자**
- 이벤트 목록 조회 (이벤트명 부분 검색, 상태 필터, 페이지 단위)
- 이벤트 등록·상세 조회·수정·삭제
- 당첨 발표 공지 등록·조회·수정
- 당첨자 등록, 순위순 목록 조회, 삭제

**점주**
이벤트를 다루는 점주 화면은 없다.
