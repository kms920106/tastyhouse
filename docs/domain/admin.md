# 관리자 계정(admin) 도메인

## 이 도메인은 무엇인가

관리자 계정 도메인은 맛집 서비스의 운영을 담당하는 사람들이 관리자 화면에 로그인할 때 쓰는 계정을 다룬다. 회원(웹 이용자)이나 점주와는 완전히 별개의 계정 체계이며, 회원가입처럼 스스로 만드는 것이 아니라 이미 있는 최고관리자가 만들어 주는 방식이다.

이 도메인이 관리하는 것은 "누가 관리자 화면에 들어올 수 있는가"와 "그 사람이 어느 등급의 권한을 갖는가" 두 가지다. 관리자가 실제로 하는 일(배너 등록, 공지 작성, 제휴 검토 등)은 각 업무 도메인이 담당하고, 이 도메인은 그 일을 할 자격을 가진 사람의 명단만 관리한다.

## 핵심 개념

**관리자 계정** — 로그인 아이디, 비밀번호, 이름, 권한 등급, 계정 상태로 이루어진다. 로그인 아이디는 4자에서 50자까지, 이름은 100자까지, 비밀번호는 8자 이상으로 받는다. 비밀번호는 알아볼 수 없는 형태로 변환해 보관하므로, 운영자가 다른 관리자의 비밀번호를 열람할 방법은 없다.

**권한 등급** — 최고관리자와 일반관리자 두 단계뿐이다. 중간 단계나 업무별 세부 권한 구분은 없다.

**계정 상태** — 정상과 비활성 두 가지다. 비활성 계정은 아이디와 비밀번호가 맞아도 로그인할 수 없다.

## 주요 업무 흐름

서비스를 처음 띄우면 관리자가 한 명도 없는 상태다. 그래서 최초의 최고관리자 한 명은 시스템이 자동으로 만들어 준다. 이때 쓸 비밀번호는 반드시 운영 환경 설정으로 따로 지정해야 하며, 지정하지 않으면 계정을 만들지 않고 실행이 멈춘다. 아무나 짐작할 수 있는 기본 비밀번호로 최고관리자가 열려 있는 상황을 원천적으로 막기 위한 장치다. 이미 같은 아이디의 계정이 있으면 다시 만들지 않고 그냥 넘어가므로, 서비스를 여러 번 재시작해도 계정이 중복 생성되지는 않는다.

그 다음부터 관리자 계정은 사람이 만든다. 최고관리자가 관리자 화면에서 아이디, 비밀번호, 이름, 부여할 권한 등급을 입력하면 새 계정이 만들어진다. 새로 만들어진 계정은 곧바로 정상 상태이므로 별도 승인 절차 없이 바로 로그인할 수 있다.

일반관리자는 다른 관리자 계정을 만들 수 없다. 계정을 하나 더 만들어야 하면 최고관리자에게 요청해야 한다.

로그인할 때는 아이디로 계정을 찾고, 비밀번호를 대조하고, 계정 상태가 정상인지 확인한다. 로그인이 끝난 뒤에도 권한 등급이 계속 따라다니면서, 최고관리자만 쓸 수 있는 기능에 일반관리자가 접근하면 차단된다.

## 상태와 전이 규칙

| 상태 | 의미 |
| --- | --- |
| 정상 | 로그인할 수 있다. 계정 생성 시의 기본 상태다. |
| 비활성 | 로그인할 수 없다. |

계정은 만들어질 때 항상 정상 상태로 시작한다. 지금 시점에는 관리자 화면에서 계정의 이름이나 비밀번호를 수정하거나 상태를 비활성으로 바꾸는 기능이 없다. 즉 계정 정보를 나중에 고치는 경로가 열려 있지 않으므로, 잘못 만든 계정이나 퇴사자 계정을 정리하려면 데이터를 직접 손봐야 한다. 관리자 계정 목록을 화면에서 보는 기능도 아직 없다.

## 비즈니스 규칙

| 규칙 | 위반하면 어떻게 되는가 |
| --- | --- |
| 로그인 아이디는 다른 관리자와 겹칠 수 없다 | 계정 생성이 거부되고 아이디가 중복되었다는 안내가 나온다. 다른 아이디를 입력해야 한다. |
| 관리자 계정 생성은 최고관리자만 할 수 있다 | 일반관리자가 시도하면 권한이 없다는 응답을 받고 계정이 만들어지지 않는다. |
| 비활성 계정은 로그인할 수 없다 | 아이디와 비밀번호가 맞아도 로그인이 거절된다. |
| 권한 등급은 최고관리자와 일반관리자 중 하나여야 한다 | 그 외 값을 보내면 알 수 없는 권한이라는 안내와 함께 생성이 거부된다. |
| 최초 최고관리자의 비밀번호는 운영 환경에서 반드시 지정해야 한다 | 지정하지 않으면 서비스가 시작되지 않는다. |

## 다른 도메인과의 관계

관리자 계정 도메인은 다른 업무 데이터를 직접 갖고 있지 않지만, 관리자가 수행하는 거의 모든 운영 업무의 전제가 된다. 배너 등록과 수정, 공지사항 작성, 제휴 신청 검토와 상태 변경, 약관 버전 관리, 가게 등록과 점주 배정 같은 업무는 모두 관리자로 로그인한 상태에서만 가능하다.

약관과 정책 도메인은 한 걸음 더 나아가, 문서를 만든 사람과 마지막으로 고친 사람을 기록으로 남긴다. 즉 어떤 약관 버전이 누구 손을 거쳤는지 추적할 수 있다.

점주 계정 도메인과는 계정 체계가 분리되어 있어 서로 침범하지 않는다. 관리자는 점주 목록을 조회해 가게에 점주를 배정할 수 있지만, 점주 계정 자체를 관리자 화면에서 만들거나 고치지는 않는다.

## 사용자별 접점

**관리자** — 관리자 화면 로그인이 이 도메인의 가장 잦은 접점이다. 최고관리자는 추가로 관리자 계정 생성 기능을 쓸 수 있으며, 이 기능은 최고관리자에게만 보이거나 최고관리자가 아니면 실패해야 한다.

**일반 회원(웹)** — 접점이 없다. 회원은 관리자 계정의 존재를 알 필요가 없다.

**점주** — 접점이 없다. 점주는 자기 전용 화면과 계정을 쓴다.
